# IncidentIQ — Screenshots Capture Checklist

Use this checklist to capture screenshots for your project submission:

- [ ] **1. Main Dashboard Overview**: Header showing health status badges (Gemini, Hindsight, Bank ID `prod-incidents`) and incident scenario selector.
- [ ] **2. Target Incident Selected (`INC-1097`)**: Displaying active error signature, symptoms, and recent deployment `v2.5.0`.
- [ ] **3. Memory Seeding In Action**: Toast notification confirming historical incidents retained into Hindsight bank.
- [ ] **4. Hero Demo Split Screen (Before vs. After)**:
  - Left: MEMORY OFF (Baseline) showing generic advice.
  - Right: WITH HINDSIGHT MEMORY showing recalled precedent `INC-1042`, specific root cause, and verified fix.
- [ ] **5. Recalled Historical Precedent Card**: Highlight showing relevance score (95%), past symptoms, and past verified fix.
- [ ] **6. Post-Mortem Retain Modal ("Resolve & Remember")**: Form capturing confirmed root cause, effective resolution, and preventive actions.
- [ ] **7. Live Hindsight Memory Explorer**: Cards showing stored incident post-mortems in bank `prod-incidents`.
- [ ] **8. Architecture Diagram**: Mermaid diagram rendered from `docs/architecture.md`.
